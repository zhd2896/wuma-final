# 阶段二审查记录

基线 `e420005`，范围为联机账号归属、恢复、个人历史与迁移。

规格首次审查发现：联机复盘分析期间账号退休或令牌轮换后，最终 `commit_review` 没有复验账号与席位，仍能保存结果。审查者使用真实内存 API 复现两种情况。实现增加保存事务内账号、令牌和本人视角校验，并在异步读取及缓存返回后重新验证权限。

规格复审独立运行两项新增内存回归通过，确认退休账号返回 401、轮换令牌返回 403，均没有保存复盘；其余规格结论保留，规格审查通过。质量审查另行进行。

质量审查另发现：没有本机席位令牌时，首次账号恢复遇到网络失败，页面重试只刷新尚未建立的房间，导致无法重新请求恢复。要求保留待恢复棋局 ID，并测试失败后再次恢复成功。

实现保留待恢复 ID，重试先处理原操作请求，无房间时重新恢复；成功及离开时清空。质量复审独立运行 7 项恢复测试通过，无新问题，质量审查最终通过。

父代理独立验证前端恢复、返回导航与复盘页面交互，共 20 项通过。完整阶段证据见 `docs/remote-account-acceptance.md` 及对应日志。

最终验证：前端全量 472 项、后端全量 226 项全部通过，无跳过；类型及页面检查通过。后端使用真实隔离 MySQL 与新空库迁移。前端最后日志为 `results/staged-phase2-final-frontend.log`。
