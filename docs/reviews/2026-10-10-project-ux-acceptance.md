## 提交前启动修复与复验

用户在微信开发者工具报告首页 `module 'guide/trial-controller.js' is not defined`。原因是新增首页服务静态引用了尚未加载的 `guide` 分包。把草稿校验恢复抽到主包 `services/trial-draft.ts`，课程数据抽到 `services/tutorial-lessons.ts`；首页和分包共用，保持真实棋谱回放校验及七关进度语义。

新增回归使用 TypeScript 转译后的真实首页依赖，在分包不可用时加载页面。修复前准确复现模块不可用，修复后首页成功注册并执行 onShow。源码检查新增主包引用分包、跨分包引用及独立分包依赖限制；测试覆盖 import、export、require、动态 import，并允许纯类型引用和普通分包使用主包。

修复后的完整前端回归：664 项通过，0 失败、0 跳过。相关后端回归：47 项通过、49 项 MySQL 跳过；联机及本地导入接口回归另有 30 项通过，合计 77 项通过。类型、15 页面/20 组件及分包依赖检查通过。微信开发者工具随附的 wcc/wcsc 可执行编译器已分别编译全部 WXML/WXSS；此检查与仅加载主包的回归不代替实际模拟器或真机渲染。

更新源码后，在微信开发者工具中清除编译缓存并完整重新编译。后端未拉取新代码不会导致该主包模块加载错误；服务器更新仍需按部署文档 git pull 后重新构建镜像，仅重启不会更新镜像中的代码。
