## 三、另行收口的事项

这些事项与“功能代码未实现”分开处理：

1. **体验版 / 正式版配置**：`miniprogram/config/api.ts` 的 `test` 和 `production` 地址为空，需要实际 HTTPS API 地址和微信合法请求域名配置；开发地址为本机 `127.0.0.1`，不能直接作为手机访问的部署地址。
2. **真实环境验收**：微信登录、MySQL 持久化与迁移、两台真机联机、跨设备历史及终局复盘还需要对应环境验收。本次静态检查未验证本地密钥是否齐全，也未调用微信登录服务，不能据此断言服务已配置或可真实登录。
3. **过期展示文案**：首页仍显示“UI 演示阶段”，认输确认仍为演示说明；需要随实际实现更新。旧 Mock 服务仍有导出，但当前分析、教练、复盘和历史页已接真实链路，不能据文件名将这些模块判定为未实现。
4. **个人资料完善（体验扩展）**：个人头像仍是固定“棋”字；昵称有读取与默认值，但没有用户自主设置昵称、头像的页面及保存接口。此项与微信登录本身分开，不影响登录会话功能已经有代码实现的结论。
