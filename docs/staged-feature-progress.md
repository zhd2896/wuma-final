## 执行方式

沿用现有棋规引擎、API 响应结构、鉴权和事务模型；优先复用已有设计。每阶段先写行为测试并确认缺口，再实现与验证，审查通过后记录结果。保留微信登录、旧历史和已完成的对局操作，不引入 Mock 业务数据。

各阶段测试记录存放于 `results/`；具体设计和实现计划存放于 `docs/superpowers/`。不自动发布、不改业务数据库、不修改本地密钥。
