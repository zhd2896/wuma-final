# 对局称呼与操作引导验收

日期：2026-10-07。本地分支：codex/game-player-guidance，基于 dbcbac3。

## 用户可见改动

- 双设备联机依据房间席位显示你／对手，并显示黑方、红方颜色与各自备用棋；本地以及没有独立席位的远程单棋局使用黑方／红方。AI 对局使用你／AI，并保留难度。
- 回合提示移到棋盘上方，说明先选棋子、已选棋子的中文位置以及可走目标数量。显示设置关闭时明确提示，不把隐藏标记解释成没有合法走法。
- 可走目标与吃子换入节点增加文字标记，配合原有高亮；文字不拦截触控。点位编号继续可选，默认不开启。
- 吃子摘要按真实规则或服务端结果说明攻击方、被吃方、夹吃／挑吃、数量、换入和备用棋消耗。备用棋不足时显示未生效。本地选子保留最近吃子反馈，下一步覆盖，悔棋与旧记录恢复清空。
- 联机悔棋协商时显示棋盘暂停；提交中显示处理中，请求结束仍未确认时才提示重试原请求。终局原因按败方称呼显示。
- 操作集中在辅助区，注明落子直接操作棋盘；本地与远程单棋局移除重复的提示按钮，仍可进入分析。AI 走棋提示保留。
