# 能力分析图表切换验收

日期：2026-10-07。实现位于 `codex/staged-completion` 分支的 `.worktrees/ability-charts` 工作区，主工作区 `main` 保持原状态。

## 使用方式

登录后进入“我的棋力”，在“能力分析”上方选择“雷达图”“条形图”或“折线图”。默认雷达图，设备记住所选展示模式；切换不产生额外接口请求。折线图展示当前六项能力的分数对比，明确标注“非时间趋势”，不代表历史成长。

三个模式共享现有个人能力接口与 0–100 分尺度。真实 0 分正常显示；样本不足显示“待评估”，不绘制为 0 分，连线不跨过缺项。评分依据、样本门槛和指标说明保留。页面隐藏、重新加载及退出登录时清空个人图表数据，防止账号之间残留。
