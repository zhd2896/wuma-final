## 已完成功能

### 1. 本地真实局面分析

- 对局页传递当前本地棋局 ID。
- 分析页从设备历史读取该棋局保存的完整 `GameState`。
- 使用前端真实 `analyzePosition` 引擎计算，不请求后端。
- 后端断网时仍可分析。
- 没有明确棋局 ID 时尝试读取 `activeLocalGameId`；仍无棋局则展示开始对局和历史对局入口。

### 2. 云端权威局面分析

- 对局页传递当前云端棋局 ID。
- 分析页先通过 `GET /api/v1/game/{gameId}` 读取权威状态及版本。
- 再调用 `POST /api/v1/ai/analyze`，请求携带相同 `expected_version`。
- 返回棋局 ID 或版本不一致时丢弃结果。
- `GAME_STATE_CONFLICT` 显示“棋局已变化，请重新分析”，重试会重新读取权威版本。

### 3. 三个真实页签

- **局面评估**：当前静态评分、最佳搜索评分、七项评分分解、真实棋盘、真实威胁及搜索信息。
- **关键棋子**：从真实威胁节点、威胁走法和候选走法起点中提取，只展示当前棋盘上实际存在的棋子。
- **推荐行动**：真实最佳走法、候选走法、排名及引擎评分；终局不生成推荐走法。

### 4. AI 对弈共享映射

- AI 对弈继续使用已接通的实时分析接口。
- AI 页面和独立分析页现在共用 `analysis-view-model.ts`。
- 评分分项、威胁名称、候选走法和分数视角不再由两个页面分别解释。

### 5. 异步和错误保护

- 分析期间阻止重复请求。
- 页面卸载或新请求开始后，旧响应不能覆盖新状态。
- 本地存储异常、网络异常、棋局不存在、无权访问和版本冲突均不会回退到演示数据。
- 空棋局、错误和版本冲突均保留明确操作入口。
