# 首次免登录体验验收（2026-10-07）

## 用户流程

首次打开小程序进入首页，能直接浏览玩法、完成三关实操教学或开始免登录电脑试玩。首页保留微信登录入口，登录页增加返回首页继续体验。冷启动图解页返回也可直接到公开首页。

离线试玩使用标准规则与随机合法走子的电脑，用户执黑先走；支持合法落点提示、备用棋及吃子说明、认输、终局、重新开始和退出恢复。它与正式入门/标准/进阶 AI 对局分开标识。未保存前不调用云端、不写个人历史或棋力；临时草稿仅存在本机。恢复时校验编号和完整棋谱，使用实际规则重放，损坏时保留原草稿并提示显式重开。

有棋步后点击保存才引导微信登录，返回原试玩页后保存原棋谱。已登录用户直接保存。复用现有本地棋谱导入，以 LOCAL 模式记录，不冒充正式 AI 对局。保存开始后冻结原局；结果未知时原样重试，不能覆盖 pending 棋谱，账号和服务地址沿用既有同步绑定。不同内容不能借用已有编号保存。成功后可查看个人历史，并清理匹配的临时草稿；后台晚到结果不会删除新开的草稿。

联机、正式 AI、个人历史、训练、学习和个人资料等私有功能，在导航前检查会话；未登录者进入登录页并保留目标参数。冷启动私有深链仍受保护。没有配置体验版 API 地址时，首页、教学和离线试玩可用，微信登录及云端保存仍显示服务暂未开放。
