# 成长反馈验收

日期：2026-10-07。本地分支 codex/growth-feedback，基于 fe8794e。

## 已实现

- 我的棋力在个人统计之前展示可点击的下一步任务，包括吃子、防守、孤棋主题。点击直接进入精选训练，主题及难度筛选同步，原有筛选和复盘来源入口保留。
- 最近7天每个主题完成两道不同题为目标，按真实正确作答推进；重复提交及重复完成同题不重复推进，完成后可继续巩固，跨时段可以复习旧题。
- 最近28天至少三道首次无提示作答才评估主题正确率，薄弱主题优先，其次未完成目标。按原始正确比例推荐入门／进阶，不把四舍五入后的75%误当作已达门槛。
- 比较最近7天与前7天的不同题完成数，呈现14天每日完成柱图。两个时段都至少有三道首次无提示作答才比较正确率；样本不足有明确提示，训练变化不等于棋力评分变化。
- 时间按上海日期计算。完成允许提示，正确率仅计每个观察时段内每题的首次作答且没有使用提示；题目有多个主题时可计入相关主题，因此主题数量不可简单相加。
- 后端 GET/POST /api/v1/me/profile 增加 growth_v1 数据，内存和 MySQL 使用同一个计算函数，SQL按账号与28天时间窗口取证。前端验证去重口径、比例、日期序列与统计一致性。
- 切换账号、隐藏、退出或请求失败时清空成长数据，迟到响应不能写回。旧服务没有 growth 字段仍可显示原有资料，成长区域提示暂不可用。
