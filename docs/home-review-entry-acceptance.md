# 首页复盘入口阶段验收记录

日期：2026-09-28

## 阶段范围

首页“棋局复盘”卡片应引导用户选择当前真正可复盘的已结束棋局。现有本地双人终局只有终局棋盘，尚未具备服务器复盘，因此不能作为可复盘棋局展示。普通历史页继续保留本地终局。

## 已实现

- 首页与教练页的复盘入口统一进入 `filter=reviewable` 的本机历史页。
- 复盘筛选只展示已结束的 AI/服务器双人棋局；普通历史和原有 `filter=finished` 行为保持可用。
- 没有可复盘棋局时显示“还没有可复盘的棋局”，说明需要完成一局 AI 或云端对弈，并提供“开始 AI 对弈”操作。
- 首页卡片添加稳定的元素 ID。隔离库复盘 E2E 脚本改为从首页实际点击卡片，再走历史列表到复盘页。

## 尚待验收

- “已结束的真实服务器棋局 → 首页卡片 → 本机历史 → 复盘页”仍需隔离 MySQL `*_test` 数据库及已结束测试棋局。`npm run test:e2e:history-review` 已覆盖这条路线，但当前缺少 `WUMA_TEST_DATABASE_URL` 与 `WUMA_HISTORY_E2E_GAME_ID`，不能安全执行。该端到端路径未通过前，本阶段不标记完全验收。

## 阶段判定

首页卡片导航、筛选规则和无可复盘棋局的行为已实现并通过真实开发工具验证；完整服务器复盘链路**待验收**。按阶段门槛，**暂不进入后续阶段**。
