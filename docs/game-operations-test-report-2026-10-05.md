## 本次发现及修复

1. **真实迁移失败**：测试库默认 `utf8mb4_unicode_ci`，0001 的显式 `utf8mb4` 表使用服务器默认排序规则，后续表继承库排序规则，0004 外键报 MySQL 3780。后续 11 张表补齐与 0001 一致的字符集选项；原缺陷回归先失败，修复后空库升级通过。提交：`9e28b6d`。
2. **真实 IDE 脚本连接失败**：取出 `miniprogram-automator.connect` 后调用丢失实例上下文，报 `launcher` 未定义。改为保留实例调用，并增加走默认连接路径的回归。提交：`271caad`。
3. **新增迁移测试的隔离检查**：审查发现 URL 查询参数可覆盖库名。增加参数白名单及实际数据库名核对，10 项拒绝/错配回归通过。提交：`c13485c`。

上述修复代码审查通过。已有数据库不会重新执行已应用迁移；本补丁没有调整原有业务表的排序规则。
