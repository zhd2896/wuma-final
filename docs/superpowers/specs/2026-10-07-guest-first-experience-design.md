# 首次免登录体验

用户要求保留微信登录，先免登录教学试玩，保存记录与联机时再登录。采用公开首页 + 既有教学 + 独立离线电脑试玩页。相比只调整登录按钮，公开首页能先展示游戏价值；相比直接开放正式对局页，独立试玩页不会触发云端棋局或记录接口。

## 入口和鉴权

app.json 首页面改为首页。首页、玩法图解、新手实操和 guide/pages/trial/trial 为公开页面，未部署 API 时仍可访问。登录页始终可打开，并增加返回首页体验入口。公开路由严格匹配。openPage/openTab 在导航前检查会话，私有记录、正式对局、联机、训练和个人资料保留登录要求及原目标参数；App 冷启动深链继续同样保护。

首页突出「先学三步」「免登录电脑试玩」和「微信登录」，说明保存棋谱和联机需要登录。已登录用户保留原功能卡片及历史入口。教学完成页增加免登录电脑试玩，已有正式入门 AI 按钮保留。

## 试玩

guide 分包的独立试玩页使用本机 RuleEngine 与 RandomAI，黑方为用户且先手，红方为随机合法走子的电脑。使用完整标准棋盘，显示合法落点、回合、备用棋、吃子反馈及终局。支持重新开始、认输和返回；不进行账号或云端请求，不写个人历史及棋力。文案明确该电脑是离线随机走子，正式 AI 仍需登录。

临时棋谱以版本化 draft 保存在本机，退出再进通过真实规则从初始局面重放恢复；限制 2048 步、校验 ID/节点/轮次/认输，损坏时说明并让用户显式重开，不覆盖原数据。草稿不作为正式个人记录。

## 保存与登录

试玩有棋步后点击「保存棋谱」才进入微信登录，登录后返回试玩页 save=1 并保存原棋谱。已登录时直接保存。复用 DeviceHistoryStore 和 syncLocalScore 的幂等、账号绑定及 pending/linked 状态，不新增后端接口。棋谱按本地对局保存，不标记成正式 AI 棋局。

开始保存后冻结该局，避免失败重试时棋谱改变；保留临时棋谱和同步凭据。保存成功可打开历史。重新开始只能在未发送同步时或确认同步成功后进行；pending 状态必须先重试，不丢失结果未知的记录。无云端配置或登录失败时仍保留试玩。联机按钮登录后进入原联机页面。

## 验收

游客首次首页没有登录/API 请求；教学及试玩离线可操作、恢复及终局符合规则；私有入口导航前登录，路径参数保留。保存前不写正式历史，登录返回重放同一棋谱、保存成功与失败重试、pending 冻结、损坏草稿保护测试。全量前端、类型和页面结构检查；真机及已部署微信接口验收单独记录。
