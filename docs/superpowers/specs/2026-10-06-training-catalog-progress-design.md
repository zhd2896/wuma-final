# 阶段三：残局题库、筛选与个人训练进度

## 目标

首页的“残局挑战”进入经过引擎验证的精选残局，新用户无历史棋局也能训练；保留私有复盘失误题。训练可筛选题源、失误类别、难度、完成状态和来源棋局，重登后显示本人最近结果，重复作答不虚增完成题数。

## 题源与难度

采用统一训练题模型，增加 `sourceKind=REVIEW|CURATED`、题目标题、题库版本；精选题不依赖伪造棋局或复盘，现有来源外键允许为空。现有复盘题仍保留真实来源、版本与评分配置。新增可重复加载、稳定 ID 的精选题目录，至少三个不同的合法残局；入库时用唯一棋规引擎验证合法走法与答案评分。目录与答案计算版本一并记录，不能返回未经验证的题目。

读取与列表 DTO 继续隐藏最佳走法、最佳评分和原始错误走法。展示题源、题目描述、难度依据和当前用户进度。精选题对已登录用户公开，复盘题只对资源所有者或合法本人视角参与者开放，不能为了公开题库放开私有历史。

难度不得假称经过玩家测试。第一版使用可复算的引擎复杂度标记：合法候选数与固定评分配置生成简易/一般/复杂档，并明确这是引擎估计；旧题保留“待校准”。评分仍使用题目保存的分析配置，与对弈 AI 难度无关。

## 进度与列表

- 后端按用户与题目读取最近一次结果、尝试次数，以及是否至少有一次正确作答。完成表示已正确完成，尝试表示已作答，两个状态分开。
- 个人页的 `training` 表示去重后的已完成题数，新增 `trainingAttempts` 表示实际作答次数；正确率仍基于全部作答次数。
- 列表筛选覆盖题源、复盘失误类别、难度、完成状态、`source_game_id`，总数必须与同样筛选一致。先过滤后分页，稳定排序。
- 前端切换筛选清空旧页，异步请求用代次隔离，过时返回不能混入当前筛选。题目作答成功后同步当前列表进度；重试提交保留同一请求号。
- “下一题”优先跳过已完成题，必要时加载后续页；没有未完成题时返回列表并说明，不停在无反应状态。
- 从复盘生成训练题后携带来源棋局进入复盘题列表；首页默认精选题，底部训练入口允许切换两类题源。

## 数据与错误

新增迁移衔接阶段二的唯一 head。训练题源相关字段与可空来源外键改动保留现有数据，进度从真实答题记录聚合，不另写容易漂移的完成计数。

题库加载失败、答案评分未达到保存深度、非法走法、请求号冲突和网络超时均沿用结构化错误；失败不能改成“已完成”。昵称或其他账号信息不得进入公共题目列表。

## 验收

新用户可列出精选题并完成真实引擎答题；读取不泄露答案；两用户答同一公开题进度隔离；重复请求不重复保存，重复作答不重复累计完成题数；全部筛选与分页总数一致；从某局生成后只显示该局训练；旧复盘题及权限不回归。验证真实 MySQL 持久化、迁移及前端交互测试。
