# 阶段七：联机分析、复盘解释与个人训练

## 目标与入口

已有联机席位复盘和账号归属继续复用。联机对局提供局面分析入口，已结束的联机复盘提供解释和生成训练入口，使真实参与者可以按自己的席位学习。

分析页来源新增明确的 `online` 模式，不能把联机棋局传给普通棋局接口，也不能落到本地存档分析。通过阶段二的席位恢复辅助函数获得有效凭据，再获取当前房间及版本并请求分析；过期结果与卸载后的返回不显示。分析可从已结束的当前局面读取，房间取消、等待或过期时给出明确状态。

## 服务与权限

- 联机路由使用当前微信用户、房间席位令牌及预期棋局版本；复用唯一引擎和已有分析 DTO。分析前后验证版本与当前参与者，不能把已更换席位、已合并账号的结果返回旧账号。
- 普通棋局接口继续拒绝 REMOTE。在服务内部提供显式受控的复用路径，不为方便调用而放开通用接口。
- 解释服务读取该用户本人的已保存席位复盘，复用已有事实约束、缓存及无 LLM 时的规则解释。解释生成前后验证权限，缓存保存不能越过账号失效检查；相同复盘配置下重复调用保持一致。
- 联机训练只生成本人席位的失误与严重失误题，不生成对手的私有题。来源、复盘视角、评分配置及深度保留；事务保存重新验证当前参与者。
- 训练列表、读取与作答使用账号归属访问自己的联机题，无需永久保留设备令牌。两席位产生的题目隔离，公开精选题规则不变；账号合并按原有迁移语义更新访问归属。

实际模型只有答题记录具有 user_id，训练题尚无所有者列。增加 `0018_remote_training_owners` 迁移，为训练题保存可空的账号所有者和索引，外键继承用户主键的真实排序规则。旧普通棋局题保留按棋局所有者访问的兼容方式，公开精选题不绑定所有者；账号合并迁移私有题归属。存在归属记录时拒绝会丢失归属信息的降级。

## 页面行为

复盘的解释、训练按钮根据实际模式选择接口，不能继续显示“联机暂不支持”。生成后进入该棋局、本人视角的训练列表；无失误时说明没有可生成题目。局面分析显示自己的席位和分析方，棋盘候选路线及风险说明沿用现有组件。

加载、重试、权限变化、版本冲突、无题目与引擎失败均有明确反馈。不得修改真实棋局、搜索评分或胜负统计来制造解释内容。

## 验收

两账号在同一结束棋局读取自己的复盘和解释，只能列出自己的私有训练题；第三账号及错误令牌拒绝访问。测试分析版本冲突、账号合并期间的提交、无 LLM 的解释、训练答案隐藏、重复生成幂等，以及前端入口和不同模式路由。运行内存与真实 MySQL 验证，真机验收另记待办。
