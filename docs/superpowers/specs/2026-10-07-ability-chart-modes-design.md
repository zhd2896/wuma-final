# 能力分析图表切换

用户已确认实现此前展示的方案：雷达、条形、折线三种切换，默认雷达，折线表示当前六项能力对比，不表示时间趋势。当前功能分支已有 player_skill_v1 实战表现、最佳着率、决策质量、稳定性、失误控制、训练掌握六项评分，范围 0–100，样本不足为 null。主工作区 main 保持不变，在独立 worktree 继续 codex/staged-completion。

## 呈现

相比加入通用图表库，复用原生 WXML/WXSS 绘制点、线、标签和条形，无新增依赖、Canvas 异步绘制或接口改动。相比把各指标折线称为成长趋势，明确标注「当前六项能力对比（非时间趋势）」。未来日期趋势需真实历史快照，不纳入本阶段。

独立 skill-chart 组件接收经过已有接口校验的 metrics 和 mode，使用纯 chart-model 计算归一化坐标。所有模式统一 0–100 范围、相同指标顺序与真实分数；点击切换不会请求接口或修改评分。顶部三个按钮显示当前模式，记录本机展示偏好，非法偏好回退雷达。

雷达有五级网格及六条轴，显示各指标名与分数；只有有值的指标画点，相邻有值指标才连线。条形显示水平刻度和六项值；0 分显示真实 0 分，null 不绘数据条且标「待评估」。折线横轴为六项能力，纵轴 0–100，缺值断线，不跨缺值插值。部分和全部数据不足时均保留轴及清楚提示。

现有样本数量、阈值、指标说明及统计参考声明保留在图表下，提供评分依据。页面加载、错误、换账号、隐藏、退出登录时继续清理旧账户数据。图表派生数据随输入重建，不保留旧账号图形；切换偏好只包含模式、不含分数。

## 验收

纯模型验证坐标、0/100、缺项及全缺项、断线、稳定顺序、不修改原输入。真实 Component 测试属性更新和换模式后清理旧点；真实 Page 测试三种切换无 API 请求、偏好读取/保存失败回退、换账户/退出清图。执行完整前端、类型及结构检查。实际微信绘制/触控、不同屏幕大小未运行则列为待验收。
