# 对局称呼与操作引导设计

联机依据房间 seat 显示你／对手及所执颜色；本地共享棋盘与无独立席位的远程单棋局显示黑方／红方。AI 对局显示你／AI。状态提示置于棋盘上方，明确当前回合、已选棋子、可走数量；网络提交、悔棋协商和未确认操作优先显示真实等待状态。

可走目标在已有绿色圆点上加文字标识，吃子与换入使用真实 CaptureResult 显示标记及摘要，尊重显示设置。点位编号继续可选，日常操作提示使用中文位置名。局面分析、悔棋等保留原有权限与确认逻辑，集中为辅助操作区。

不改变规则、请求、席位权限、保存格式。旧本地记录缺少吃子信息时不编造，本地悔棋清空最近吃子标记。自动测试覆盖两种联机席位、本地选择/移动/悔棋/终局、设置关闭和网络等待。
