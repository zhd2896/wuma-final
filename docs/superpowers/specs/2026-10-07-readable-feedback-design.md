# 复盘与答题反馈阅读层级

按用户明确要求，首屏先展示关键失误、原因、推荐走法，技术数据可展开，分类改为中文。

复盘在棋盘前展示本方最多三个关键失误，严重失误优先，同级按评分损失排序；按钮定位已有最佳路线预览。无失误或无本方落子分别说明，不凭空制造失误。逐步复盘同样显示中文分类、简明原因和推荐点位。

训练答题完成后先显示“走法正确/还有更好的走法”、原因、推荐走法和实际走法。解释优先使用已验证的教学内容；个人复盘题无具体教学说明时使用保守提示，不假造吃子或防守因果。答题前隐藏全部答案。

共用原生可展开详情组件，默认收起；换复盘、视角、回放步骤或答题记录时重置。评分、搜索深度、版本、完整引擎解释保留在详情。中文展示映射覆盖走法分类、终局原因及吃子未生效原因，不改变 API 枚举、评分和记录。

自然语言解释可能含分数或英文分类：首层去除明确的技术分数句并翻译已知分类，完整解释仍保留详情。不依赖自然语言接口成功才能显示基本反馈。回放、联机席位和账号校验、训练题库及试玩校准均保留。
