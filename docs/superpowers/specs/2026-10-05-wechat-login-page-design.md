# 微信登录界面设计（已确认）

## 推荐流程

首次进入小程序显示独立登录页，沿用现有水墨视觉风格。展示“弈智五马”、简短登录说明、“微信账号登录”主按钮及登录失败提示。用户点击按钮后才调用 wx.login 和后端 /api/v1/auth/wechat；按钮处理中禁用，避免重复提交。成功保存会话后进入首页。

已有有效会话的用户重开直接进入首页。未登录或会话失效时进入登录页，业务请求不隐式创建登录身份。个人中心提供退出登录，清除本机登录会话并返回登录页，云端用户数据保留。

深链打开个人记录或在线功能时检查登录态，登录成功后恢复允许的目标页面。保持后端微信验证、匿名数据迁移和所有权校验；不要求用户输入微信账号密码。

## 替代方案

只在个人中心加登录入口，首页可直接访问。改动较小，但用户进入在线功能时仍会被要求登录，入口不如独立首次登录页明确。

## 验证

测试未登录进入、有效会话跳过、按钮重复点击、成功导航、失败留在登录页、退出不删除历史、会话失效跳转及登录后的目标页恢复。运行小程序完整单元测试、类型检查和页面结构检查。真实微信登录仍依赖已配置的 AppSecret 与可用后端。
