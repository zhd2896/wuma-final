# 分主题训练题实施计划

**Goal:** 入门与进阶每个主题都有可答精选题，并以首次答题结果提供诚实的试玩校准建议。
**Architecture:** 正式引擎验证的版本化题库；现有训练标签主题筛选；现有答题记录汇总的校准 DTO；原生训练页面显示目标及答案后解题说明。
**Tech Stack:** Python/FastAPI/Pydantic/SQLAlchemy/MySQL，TypeScript/WXML，pytest/Node test。

- [x] 1. 先增加后端题量、分级、主题交集和校准去重的失败测试；正式引擎探索并验证候选局面。
- [x] 2. 扩展题库与兼容 DTO；内存与 MySQL 同步增加主题筛选、入门优先排序、首次答题统计；不改变旧题 ID 和答案。
- [x] 3. 先增加前端实际筛选与渲染测试，接入中文主题、入门/进阶标签、教学目标、答案后说明和试玩状态。
- [x] 4. 逐题真实走棋验收，前后端回归、类型和结构检查、SQL 编译检查与独立审查；保存验收报告及本地提交。
