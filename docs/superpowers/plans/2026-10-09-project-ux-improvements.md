# 五马棋体验改进实施清单

> 使用 subagent-driven-development 分阶段执行，逐项实施、验证后继续；不提交或部署已有混合工作区。

**Goal:** 按用户已批准的 17 项审查建议改善五马棋完整使用流程。

**Architecture:** 延用现有微信原生页面、规则引擎、请求幂等与历史存储。学习入口公开；云端操作按既有账号保护。试玩保存明确归档，不把随机电脑试玩变成双人续局。联机状态由服务端真实数据驱动。

**Tech Stack:** TypeScript、WXML/WXSS、Node test、FastAPI/Pydantic、pytest。

已获授权：用户“按你的建议一个一个修改”。实施按下列顺序完成，不重复请求批准。

- [x] 保留已有三关与本机进度，处理旧完成进度，使新增关卡可学习。
- [x] 用行为测试覆盖新关卡的真实结算、未完成不可跳关、独立练习不预告答案；16 项测试、typecheck 与 check 通过，独立代码审查通过。
