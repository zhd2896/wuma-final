# 五马棋点位编号与讲解对应实施计划

**目标：** 将用户已同意的 P01—P29 点位对照、复盘与教练高亮、实战编号开关接入当前项目。

**设计：** 棋盘组件统一绘制编号，沿用现有节点坐标和棋规 ID。讲解页使用从共享节点坐标和连线生成的编号 PNG，支持点击放大；分析和教练展示当前真实局面的推荐路线。复盘接口在返回时关联已有有效棋步的走前快照，前端以该快照展示实际或最佳路线，不使用终局棋盘推测旧位置。新增设置兼容旧版本并保留原有选择。

**技术：** 微信原生 WXML/WXSS/TypeScript、共享棋盘组件、FastAPI/Pydantic。无需数据库迁移。

## 文件职责

- miniprogram/utils/board-guidance.ts：只读点位说明与箭头坐标。
- miniprogram/components/chess-board/：统一编号和高亮。
- miniprogram/services/game-settings.ts、components/game-settings/：默认关闭及旧设置兼容。
- miniprogram/guide/pages/rules/：编号对照与说明。
- miniprogram/pages/analysis/、coach/、review/：当前讲解与图示联动。
- backend/app/schemas/game.py、services/game_service.py：返回已有真实棋步快照，不更改棋规与历史数据。
