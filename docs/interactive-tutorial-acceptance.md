# 操作式新手教学验收（更新：2026-10-09）

## 功能

首页「新手实操」、登录页「新手实操：走棋、吃子与围堵」、玩法讲解页「亲手试一试」均进入 guide/pages/tutorial/tutorial。教学在本机运行，无需登录、网络或已部署 API。

1. 走棋：黑棋 P11 → P12。
2. 夹吃：黑棋 P08 → P13，与 P11 夹住 P12 红棋。实际规则结果吃一枚，使用一枚备用黑棋替换 P12。
3. 挑吃：黑棋 P08 → P13，走到 P12/P14 红棋中间。实际规则结果吃两枚，使用两枚备用黑棋替换 P12/P14。
4. 备用棋不足：同一挑吃局面只有一枚备用黑棋；走棋保留，红棋不替换，备用棋不消耗。
5. 部分受堵：黑棋 P07 → P03 堵住庙内 P26，P25 红棋仍可走，对局继续，并列出真实规则返回的红方路线。
6. 孤棋围堵：红方只剩 P26；黑棋 P07 → P03 后真实换手、判定 TEMPLE_TRAP。进入庙内本身不判负；庙外孤棋无路可走也会判负。
7. 独立练习：P26/P29 两枚红棋，黑棋自由选子和合法落点，无推荐答案；所有经真实引擎判定 ALL_PIECES_IMMOBILIZED 的解均可通过（含 P07 → P03、P09 → P03）。未获胜的合法尝试保留实际落子、展示红方走法，重练后可再试。

棋盘显示你执黑、点位编号；前六关有源与落点标记，独立练习仅在选子后显示全部合法落点。非法操作不改变局面或推进关卡。每关完成后有规则解释，点击下一关继续，支持重练本关；退出再进恢复当前关，完成后可重新学习。检查点仅存在本机，不计入账号棋力、训练或历史。新版保存在 wuma:tutorial:v2，兼容旧 v1；旧版三关已完成者从新增第四关继续，不跳过新增内容。

完成后点击「开始入门 AI 对局」才发起正式对局。未登录时通过现有微信登录保留目标参数；已登录则新建 BEGINNER、人类先手棋局，不恢复旧棋局，不修改默认难度。创建失败保留原活动棋局 ID；旧棋局仍可从历史恢复。正常 AI 入口继续原有恢复逻辑。
