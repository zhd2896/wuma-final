# 用户与个人数据阶段验收记录（2026-09-28）

## 状态

**账号与个人历史核心链路已实现，完整阶段暂未通过验收。** 用户指定匿名设备账号；远程双人阶段暂停，本阶段没有接续其 MySQL 与双真机验收。

## 已实现

- `POST /api/v1/auth/device` 创建匿名账号并返回一次性随机凭证；数据库只保存 SHA-256 摘要，前端按 API 环境保存在本机。重开小程序沿用同一凭证。
- 生产 `create_app()` 默认强制鉴权；AI 与服务器本地棋局创建绑定 `users.id`，读棋局、落子、分析、教练、复盘、生成训练题均校验所有权。旧 `user_id = NULL` 数据不自动认领。
- 训练题只列出当前账号棋局产生的题；读取、答题校验来源棋局归属，答题记录绑定当前用户。
- `GET /api/v1/me/profile` 返回本人真实对局、AI 胜负、复盘数、训练完成与正确数；`GET /api/v1/me/games` 提供本人云端历史、终局筛选和基于不可变创建时间的游标分页。
- 个人中心移除演示开关与虚构能力值；历史页合并当前账号云端棋局和本机离线棋局。远程房间仍沿用原席位令牌，不纳入个人账号统计。
- 复用既有 `users`、`games.user_id`、`training_records.user_id`；新增迁移 `0010_personal_history_indexes`，为个人历史游标和训练统计建索引。个人历史的复盘标识批量查询。
- 供应的 Nginx HTTP/TLS 配置对设备注册按来源 IP 限流；直接公开 Uvicorn 不经过该规则。

## 已验证

- 后端内存隔离套件：72 项通过。包含两账号越权、旧匿名数据隔离、训练题与答题记录隔离、历史游标无重复。
- 前端：`npm run typecheck`、`npm run check` 通过；`npm test` 共 311 项通过，含个人中心、历史页和原有棋局页面回归。

## 尚缺最终验收证据

1. 专用隔离 MySQL 8 数据库中的迁移、双账号权限、分页、训练归属、持久化与重启测试。现环境没有 `WUMA_TEST_DATABASE_URL`，现有测试夹具会清理测试表，因此不可在日常库运行。
2. 微信开发者工具或真机上的首次建号、关闭重开、账号个人中心与历史恢复。现环境没有可用自动化端口与体验版 HTTPS API 地址。
3. Nginx 注册限流规则的部署验证。当前机器没有 Docker 或 Nginx 可执行环境，配置文件已修改但尚未执行 `nginx -t`。

匿名设备账号由本机凭证识别。清除小程序存储后无法找回原账号，跨设备个人资料同步和微信登录不在此次选择范围内。六维能力指标尚无可复算的评分公式，页面明确显示“数据不足”，这是个人中心剩余的功能项。

**判定：本阶段未验收；下一阶段可规划，但不应将该阶段标为完成。**
