# 本机历史对局阶段验收记录

日期：2026-09-28

## 阶段范围

用户选择“先做本机真实历史”。本阶段只要求此设备产生的本地双人、AI 对弈、服务器保存的双人棋局形成真实历史；可恢复进行中的棋局，已结束的服务器棋局从历史页进入现有复盘。账号、跨设备同步、旧版本中已丢失 ID 的棋局、离线本地棋局上传复盘不在本阶段范围。

## 已实现

- 新增版本化的本机历史存储：记录模式、本机首次/最近记录时间、真实手数、状态、胜方；本地双人另存实际 `GameState` 和最后一步，重进可恢复。旧云端棋局的导入时间不冒充服务器实际开局时间。
- AI 和云端双人棋局在创建、恢复和落子后写入本机索引；从历史页可按指定 `gameId` 打开旧棋局。旧版保留的活动 AI/云端棋局 ID 会经现有 GET 游戏接口导入历史。
- 历史页删除固定演示记录与空状态开关，展示真实空/成功/错误状态。未结束棋局可继续；已结束的 AI/云端棋局以正确的 `gameId` 参数打开复盘；本地终局可查看终局棋盘。
- 首页“棋局复盘”和教练页“从复盘中继续学习”现进入可复盘的已结束 AI/服务器棋局列表；普通历史仍显示本地终局。新增可恢复原有本机存储的微信开发者工具 E2E 脚本；入口专项验收见 `docs/home-review-entry-acceptance.md`。
- 代码复核后修复三类异常路径：本地落子只有写入历史成功才更新棋盘；旧棋局活动 ID 写入失败后重试仍读取原 ID；服务器旧棋局已删除时显示错误，不自动创建另一局。本地开局保存失败或历史局已缺失时也会明确显示错误。
- 已准备 `npm run test:e2e:history-review`，用于在隔离测试库和已结束测试棋局就绪后验证“服务器终局 → 历史页 → 复盘页”；当前尚未执行成功，不能算验收证据。

## 尚未取得的验收证据

- 本阶段尚未在**隔离 MySQL 测试库**中完成“已结束服务器棋局 → 本机历史页 → 真实复盘页”的微信 E2E。当前环境没有设置 `WUMA_TEST_DATABASE_URL` 和 `WUMA_HISTORY_E2E_GAME_ID`，默认 `wuma` 无密码只读连接也被本地 MySQL 拒绝；现有复盘 E2E 会创建并落子服务器棋局，不应对日常开发库执行。历史页的该路由已有页面测试，复盘后端有现有测试，但这不能代替该端到端证据。
- 登录后跨设备个人历史不在用户选择的本机范围内，仍需后续身份与归属阶段实现。

## 阶段门槛

按附件中“验收证据齐全才进入下一阶段”的标准，本阶段判定为 **未完全验收**。本机历史功能代码和本地页面 E2E 已通过；服务器已结束棋局的历史复盘 E2E 尚缺安全的隔离数据库与已结束测试棋局。取得 `WUMA_TEST_DATABASE_URL`、`WUMA_HISTORY_E2E_GAME_ID` 并在独立库中跑通这条路径之前，**不进入下一阶段开发**。
